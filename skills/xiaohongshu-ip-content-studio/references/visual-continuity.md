# 图片与角色连续性

## 页面方案

先确定有限完整的页数，默认 3:4 竖图；用户可指定比例。不因“图片不限”连续追加，不把参考稿的六页当模板。

通用字段为页码/用途、核心信息、布局/构图、逐字文字、参考资源和验收点。按形式追加：漫画的动作/对白，插画的场景，知识卡片的信息层级/来源，教程的步骤。无人物时不填对白或肢体字段。storyboard.md 是兼容文件名，内容可以是任一种静态图文页面方案。

## 固定参考

读当前账号的固定锚点与允许变化项。仅以黄小歇示例说明：托腮仅为头像姿势，半眯眼仅为常态；剧情可换姿势和表情，脸型、三道额纹、白斑与主色保持一致。其他账号使用自己的锚点，不套示例特征。

1. 先用 view_image 看尚未看过的本地参考。身份图负责人物/角色/品牌标记，风格图负责线条、材质、配色或排版；不是复刻参考布局。
2. 首图生成后实际检查身份和风格，通过才作为本篇风格锚点。
3. 每张后续页都附适用的固定角色/品牌参考与本篇首图，标明角色，必要时再附对应形式的风格参考。编辑时明确目标图、只改哪里和不变项。
4. 所有参考有路径时用 referenced_image_paths；含无路径会话图时才用足以覆盖目标的最少近期图数量。不同时提供两种机制；以当前 schema 为准。
5. 不将上一页当唯一参考连续传递，避免漂移；缺锚点不静默退回纯文字重画。

新账号用自己的资产。有角色且设定明确却无参考时，以首张合格画面建立身份锚点；不含角色的卡片用品牌配色、字体和本篇首图建立锚点，不强行加入黄猫或人像。不额外生成头像/背景。

## 提示词与调用

按 imagegen 指导选择当前形式适用的字段：用途、参考资源、布局/场景、内容主体、画风、配色、逐字文字与不变项；有叙事动作时再填写动作。共用风格块来自账号档案，每页加自己的布局/构图，需要叙事时再加镜头动作；指定中文清晰和留白，字太多先压缩脚本。

一页一次内置工具调用。首图通过后，独立页面可以并发但都保留锚点；涉及未确定的新道具形态时先确定再继续。安全边距与比例为本工作流设计选择，不冒称平台强制标准。

遵循 imagegen 的等待与输出方式，不因尺寸、路径或失败切 CLI。CLI 只在用户明确选择且密钥安全配置后使用；不向内置生图索取 API key。

## 检查与修复

每张实际查看：

- 身份：有角色时核对当前账号的脸型、标记与主色，无角色时核对品牌/栏目视觉。仅黄小歇适用三道额纹和白斑等清单，不套给其他 IP。
- 风格：按当前档案核对线条、材质、配色、字体和留白。未经用户要求不突然换画风，但不全局禁止写实、水彩、3D 或信息设计。
- 内容：文字、信息层级及适用的动作/对白正确。知识/教程内容的事实、步骤和来源对应，不伪造图表数据。
- 构图：关键内容不切边，小尺寸可读；含人物时才检查多余肢体/角色，纯信息页不强加人物字段。
- 连续性：故事检查时段/道具/关系，卡片检查层级/术语，教程检查步骤顺序；没有的叙事字段不适用。

每页初次调用后最多一次连接重试；质量不合格最多一轮定向修复，明确只改哪里。不因连接问题改参考，不为一页重生全套。

连接重试是该页所有生成/修复调用共享的总预算，不是每种调用各一次；已用掉后，修复再遇连接失败也不自动增加额度。首图未合格时不能作为后续页面的风格锚点。

仍失败记为待补，保留成功图和剩余提示词，整体 partial；说明内置工具受限及回退条件，不自行切换。重开聊天不自动清零额度，用户明确再试可记录新修订。

图片编辑仍用 imagegen，不用 Python 补字、重绘或裁画面绕过它。普通工具可以复制、读取尺寸、打 ZIP。

## 保存

保留默认生成原件，再复制到本批 images/，按顺序编号如 01-cover.png、02-page.png；修订加版本后缀。提示词引用真实存在的路径，不假设工具支持目标输出目录参数。

保存完整提示词、生成方式、参考图、最终文件和实际质检。若比例不对，在质量预算内修正或说明，不能只改扩展名。

只将合格版本列入最终图，ZIP 与发布顺序一致，不混入废弃图；部分完成包明确标为未完成。
